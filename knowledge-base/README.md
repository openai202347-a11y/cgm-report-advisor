# 知识库目录（占位）

这个目录用来放置**你自己的**指南或共识索引，以及你在本地保存的原文。本仓库只提供说明和示例索引模板，不提供任何指南正文，也不提供大段摘录。

请不要把受版权保护的全文、OCR 文本或长摘录提交到公开仓库。`.gitignore` 已经忽略 `knowledge-base/sources/`、常见公文文件以及本目录下除说明和示例模板以外的 `.txt` 文件。

开始使用时：

1. 阅读 [docs/knowledge-base.md](../docs/knowledge-base.md)。
2. 复制 `sources.example.md`（或 `sources.example.json`）为 `sources.md`（或 `sources.json`），改成你实际持有的文献记录。
3. 把原文放在不被 Git 跟踪的本地目录中，例如 `knowledge-base/sources/`。
4. 如实填写每条来源的阅读状态。未读全文的条目不得当作已掌握，也不得用来生成具体建议。

示例文件中的文献名称、年份和条目都是虚构的，只用于演示字段格式。
