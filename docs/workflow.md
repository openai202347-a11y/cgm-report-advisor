# 端到端流程

本文说明本项目建议遵循的分析顺序。代码骨架在 `src/cgm_report_advisor/` 中按同一顺序串起各步骤，但第一版并不提供各厂商 PDF 的完整解析器。

本流程用于辅助形成给患者阅读的饮食、运动和监测建议，不是正式诊疗，也不是医疗器械。

## 1. 读取报告原文

收到一份或多份 CGM 图形报告后，先从报告原文提取已经写出的信息。

- 只记录报告上实际出现的日期、覆盖情况、指标、分时描述和声明。
- 报告没有写出的数值不要补、不要估算、不要用相邻天数或“常见范围”填上。
- 单位、小数位和指标名称尽量保持原文，例如报告写的是估算糖化血红蛋白还是 GMI，就按原文记录。
- 对外文稿不要抄录报告中的掩码电话、完整姓名或其他身份信息。
- 若报告标明“仅供测试参考”或同类声明，必须在后续文稿中如实说明。

字段定义见 [report-schema.md](report-schema.md)。本仓库的提取模块只提供接口，以及从已整理好的结构化文件中载入指标的方式；不要假定它已经能解析所有厂商的 PDF。

## 2. 同一批多份报告时先核对佩戴者

如果一次传入多份报告，先核对这些报告是否属于同一佩戴者。

- 不能因为文件放在同一文件夹、或日期相近，就默认是同一人。
- 无法确认是同一人时，分开分析，不要把一份报告里的用药、病史、身高体重套到另一份上。
- 确认是同一人之后，才可以把同一监测周期内的多份报告放在一起看趋势。仍以各份报告原文为准，不要把缺失指标在报告之间互相填补。

## 3. 对照知识库，一次列出仍缺的资料

提取完成后，对照本地知识库中已收录、且已经读过全文或事先声明的选读范围的共识或指南，判断接下来的分析还缺哪些临床资料。

常见缺项往往包括：糖尿病类型与病程，用药名称、剂量和服药或注射时间，身高与体重，合并症（如心血管疾病、眼底病变、肾脏病，以及周围神经或足部问题），用餐时间与大致内容，运动习惯，睡眠时段，近期实验室测定的糖化血红蛋白。

这些只是常见例子，不是一份写死的万能问卷。

- 只问知识库在分析该类患者、或给出饮食或运动建议时确实需要的项目。
- 知识库并未要求的项不要例行索要。
- 报告或使用者已经提供的内容不要再问。
- 一次尽量问清，避免分多次补问。
- 详细原则见 [clinical-intake.md](clinical-intake.md)。知识库的导入方式见 [knowledge-base.md](knowledge-base.md)。

## 4. 决定本次输出范围

资料补齐后，再写饮食、运动和监测建议。

若使用者只想先看曲线或指标，可以先做不含饮食运动处方的指标解读，并明确标明仍缺的资料；此时不要给出具体食物份量、运动处方或与用药时点绑定的建议。

## 5. 按固定顺序解读指标

解读时采用下面的顺序，不要一开始就谈“整体控制尚可”而跳过质量和低血糖。

1. **先看数据质量。** 能否依据这份报告做判断，取决于有效监测天数和数据完整程度。不少共识常用的参考是建议约 14 天、有效数据至少约 70%，但这不是本仓库内置的固定阈值。具体采用哪一条标准、适用于哪类患者，必须以使用者导入的知识库为准，并写明来源。
2. **再看低血糖。** 先看低于目标下限的时间比例、是否出现 2 级低血糖（知识库对阈值的定义，例如低于 3.0 mmol/L 或 54 mg/dL，以已收录共识为准），以及发生的时段。2 级低血糖即便只出现一次，也应建议尽快联系医生。不要把报告软件里单独的“低血糖风险”仪表，在知识库未支持该读数、或该读数与低于目标时间（TBR）明显不符时，直接说成风险高。
3. **再看目标范围内时间、高于目标时间和变异系数（TIR / TAR / CV）等。** 指标定义、分层切点和目标值必须来自已收录共识，并写明适用人群（例如 2 型糖尿病成年门诊患者，与妊娠、老年、低血糖风险高的人群可能并不相同）。
4. **同一问题若知识库中存在不同框架，应并列写出，** 不要只保留其中一种，也不要自行折中成一条未出现在任何来源中的“综合标准”。

平均值、标准差、估算糖化血红蛋白或 GMI、极值、分时模式等，应在上述判断之后作为补充，用来解释“什么时候偏高或偏低”，而不是替代低血糖和目标范围内时间的优先顺序。

## 6. 形成可追溯的建议，并按规定配图

给患者的饮食、运动、监测建议必须能追溯到知识库中的指南或共识，并注明来源（名称、版本或年份，以及条目或章节位置，而不是大段摘录原文）。

- 知识库没有写明的用法、剂量、服药时点、食物清单、具体份量或运动处方，不要用通识补，也不要编造。
- 不建议患者自行调整处方药物剂量；涉及调药一律写咨询医生。
- 保留使用者提供的药物原名；未提供的毫克数或服药时点不要猜测。
- 每条具体、且知识库已经写明份量或动作的饮食或运动建议，可以配一张示意图。图片只图解知识库已有的份量或动作，不得为了配图而编造食物、份量或动作，也不要制作“好水果 / 坏水果”一类分类图。图上不要出现药盒商标、患者面部或身份信息。

细则见 [advice-and-illustration.md](advice-and-illustration.md)。

## 7. 写出给患者阅读的文稿

文稿应包含：监测时段和数据质量说明、按上述顺序的指标解读、仍存在的资料缺口（如有）、可追溯的建议、配图（仅限允许配图的条目），以及免责声明。

若原报告有“仅供测试参考”或同类声明，文稿中须再次写明。不要在对外文稿中写出掩码电话等身份信息。
