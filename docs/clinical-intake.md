# 临床资料收集原则

收集资料的目的，是让后续分析能够对照知识库中的共识或指南来完成，而不是先发一份固定问卷再想办法填满。

## 核心原则

1. **以知识库的需要为准，而不是以一份万能清单为准。** 只有当已导入、且已读过相应范围的指南或共识，在分析该类患者或给出饮食、运动、监测建议时确实需要某项资料，才向使用者询问该项。
2. **已经提供的不要再问。** 报告原文里已经写出的内容，或使用者此前已经说明的内容，不应重复索要。若某项只写了名称、没有剂量或时间，而知识库的建议又依赖剂量或时间，可以只补问缺失的那一部分。
3. **一次问清。** 把本次真正缺少的项目放在同一份清单里，避免分析到一半再零散追问。
4. **允许“没有”或“不确定”。** 使用者知道多少写多少。某项确定没有、不适用或暂时不知道，应如实记录，不要改写成猜测值。
5. **缺资料时缩小输出范围，而不是补写没有依据的建议。** 若饮食或运动处方所依赖的项目仍空着，应停止输出这类处方，可以只做指标解读，并标明缺口。

## 常见、但不是固定问卷的项目

下面列出的是在糖尿病 CGM 解读中经常会用到的资料。它们适合作为知识库条目映射时的参考，**不能**直接当成每次都必须问完的表单。若你导入的知识库并不需要其中某一项，就不要例行询问。

| 类别 | 可能需要的内容 | 常见用途（仅作说明） |
| --- | --- | --- |
| 糖尿病诊断 | 类型（1 型、2 型、妊娠、其他）、病程或诊断年份 | 选择适用的目标范围内时间等标准，以及是否适合某类运动建议 |
| 用药 | 名称、剂量、服药或注射时间；尤其是胰岛素、磺脲或格列奈、GLP-1 受体激动剂、SGLT2 抑制剂、糖皮质激素 | 判断低血糖风险、进餐与用药的关系；不得在缺少原名或剂量时自行补全 |
| 体格资料 | 身高、目前体重、近期体重有无显著变化 | 某些饮食或运动建议需要先判断体重相关风险；未提供则不要估算体重指数后当作已知 |
| 合并症与并发症 | 心血管疾病、眼底病变（尤其增殖性病变）、肾脏问题、周围神经或足部问题 | 决定某些运动是否不宜建议，或是否必须先写“咨询医生后再开始” |
| 进餐 | 用餐时间、主食种类和大致数量、进餐顺序 | 解释餐后偏高或餐前偏低；没有记录时，不要把某一时段的波动写成某一顿具体食物引起 |
| 运动 | 类型、时间、强度，以及和吃饭、用药的关系 | 解释运动前后的波动，并给出与知识库一致的活动建议 |
| 睡眠 | 大致睡眠时段 | 解释夜间或凌晨波动时可能需要 |
| 实验室检查 | 近期化验室测定的糖化血红蛋白（不是报告里的估算值，除非知识库允许两者对照） | 与 CGM 估算值对照时使用；缺少则不要把估算值说成化验结果 |
| 低血糖反应 | 有无症状、如何处理、有无不易察觉的低血糖 | 写监测和安全提示时可能需要 |
| 监测期特殊情况 | 是否生病、饮酒、住院或刚出院 | 这些情况可能使该段曲线不宜直接外推到日常 |

知识库如果对某一类患者（例如使用胰岛素的患者、有增殖性视网膜病变的患者）提出了额外必问项，应把这些项加入本次清单；知识库没有提出的项，不要为了“看起来完整”而追加。

## 与用药有关的特别约束

- 保留使用者或报告提供的药物原名，不要改写成另一商品名或自行判断的化学等价物后当作原始记录。
- 未提供的毫克数、单位、频次或服药时点不要猜测，也不要用“常用剂量”填上。
- 不建议在给患者的文稿中指导自行调整处方药物剂量。凡涉及改剂量、停药、加药，一律写咨询医生。

## 多份报告与多人资料

同一批次如果不能确认是同一佩戴者，每人的用药、病史、身高体重必须分开保存，不得混套。即使确认是同一人，后一份报告也不得用前一份里未在本次核对过的旧用药，直接覆盖使用者刚提供的新说明。

## 代码中的对应行为

`src/cgm_report_advisor/intake.py` 根据知识库声明的必需要素，对照报告提取结果和已填写的资料，生成一份“仍缺项目”清单。清单非空且本次需要饮食或运动处方时，流水线应停在询问步骤，而不是继续生成处方。
